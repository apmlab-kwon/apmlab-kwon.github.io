개인정보처리방침 (Privacy Policy)

시행일: 2026년 11월 23일 / Effective: November 23, 2026

1. 대상

AI-업무비서는 개발자(권용수) 본인만 사용하는 개인용 도구입니다. 다른 사용자의 구글 계정에는 접근하지 않습니다.
AI-업무비서 is a personal tool used only by its developer. It does not access any other user's Google account.

2. 사용하는 구글 데이터

개발자 본인 계정의 Google Tasks 목록 중 "업무비서" 목록의 할 일(제목, 메모, 기한, 완료 여부)만 읽고 씁니다.
The app reads and writes only the tasks (title, notes, due date, completion status) in the "업무비서" task list of the developer's own Google account.

3. 저장과 보호

데이터는 개발자 개인 소유의 서버(연구실 NAS)에만 저장되며, 인터넷에 공개되지 않습니다. 접근 권한(토큰)은 개발자의 기기에만 보관됩니다.
Data is stored only on the developer's own private server and is not exposed to the internet. Access tokens are kept only on the developer's devices.

4. 제3자 제공

구글 사용자 데이터를 판매하거나 제3자에게 제공하지 않으며, 광고에 사용하지 않습니다.
Google user data is never sold, shared with third parties, or used for advertising.

5. 삭제

개발자는 구글 계정 설정(보안 → 서드파티 앱)에서 언제든 접근 권한을 해제할 수 있으며, 서버의 기록은 직접 삭제할 수 있습니다.
Access can be revoked at any time in Google Account settings, and stored records can be deleted by the developer.
