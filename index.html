AI-업무비서

Advanced Pharmaceutical Materials Lab (APM Lab), Chonnam National University

AI-업무비서는 권용수 교수가 개인적으로 사용하는 업무 정리 도구입니다. 슬랙에 적은 일정과 할 일을 정리해 본인의 구글 캘린더와 구글 할일(Google Tasks)에 등록하고, 완료 여부를 다시 가져와 기록합니다.

AI-업무비서 is a personal productivity tool used by Prof. Yong-Su Kwon. It organizes schedules and to-dos written in Slack and adds them to the owner's own Google Calendar and Google Tasks, then reads back completion status.

  • 사용자: 개발자 본인 1명 (일반 공개 서비스가 아님) / Single user (the developer only); not a public service.
  • 사용하는 구글 권한: Google Tasks (할 일 목록 읽기·쓰기) / Google Tasks read and write.
